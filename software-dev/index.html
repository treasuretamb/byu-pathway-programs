What You'll Study

The 6 Courses in the WCP Certificate

Each course builds directly on the last and by the end, you'll have written real programs and built real websites.

CSE 110
Intro to Programming
Start here. Learn the building blocks every programmer needs like variables, loops, decisions, arrays, and input/output and use them to solve real problems. Python
WDD 130
Web Fundamentals
Discover the World Wide Web and careers in web development. Hands on design and programming, by the end you'll know if this field is right for you. HTMLCSS
CSE 111
Programming with Functions
Write cleaner, more powerful code by mastering functions, calling, writing, debugging, testing, and handling errors. Python
CSE 210
Programming with Classes
Move into object-oriented programming with classes, objects, encapsulation, inheritance, and polymorphism. The foundation of modern software. OOP
WDD 131
Dynamic Web Fundamentals
Make websites come alive. Learn to respond to events, update content, and create responsive user experiences. JavaScript
WDD 231
Web Frontend Development I
Level up: user experience, accessibility, performance optimisation, and basic API usage, skills that make professional grade websites. JSAPIs

What You'll Be Able To Do

Skills That Every Dev Team Needs

These are the foundations every software job listing is built on. Whether you're applying to a startup, a large company, or freelancing.

Programming

Write clean, functional programs that solve real problems using Python, one of the world's most in demand programming languages.

Web Design

Build websites that are visually appealing, responsive, and follow modern web standards using HTML and CSS.

JavaScript

Add interactivity to any website like dynamic content, event handling, API calls, and responsive user experiences.

OOP

Think in objects and classes, the foundation of professional software development in almost every language and framework.

Problem Solving

Break complex problems into solvable pieces and write code that works, debugging, testing, and iterating until it does.

Accessibility

Build web experiences that work for everyone, compliance with accessibility standards is now a requirement, not an option.

Getting Started

Three Steps to Enrol

No prior coding experience required, just curiosity and a laptop that can run development tools.

Step 1

Start PathwayConnect

Complete the one semester PathwayConnect foundation program. Affordable and fully online. Make sure your laptop meets the computing requirements for development work before you start.

Step 2

Apply to BYU-Idaho

Once PathwayConnect is complete, apply to BYU-Idaho to begin your WCP certificate courses and officially start your Software Development degree pathway.

Step 3

Start Building

Begin with Intro to Programming and Web Fundamentals. By the end of the certificate, you'll have built real websites and written programs that solve real problems.
